# Безопасность и модель угроз онлайн-доски (T2.6)

Документ описывает архитектуру безопасности, модель угроз, защищаемые активы и остаточные риски проекта **Онлайн-доска для уроков**.

---

## 1. Защищаемые активы

1. **Содержимое урока (снимки холста и штрихи)**:
   - Векторные элементы Excalidraw, заметки преподавателя и решения учеников.
   - Снимки доски хранятся в защищённом хранилище SQLite внутри Durable Objects на узлах Cloudflare.
2. **Идентификаторы досок (Board ID)**:
   - 22-символьные криптостойкие Base62 токены энтропии ~131 бит (генерируются через `crypto.getRandomValues`).
   - Идентификатор доски является секретом доступа (capability token): любой обладатель ссылки `/b/<id>` может читать и редактировать доску.
3. **Бесплатная квота Cloudflare Workers**:
   - 100 000 входящих запросов в сутки.
   - Защита от исчерпания вычислительных ресурсов и превышения лимитов.
4. **Конфиденциальность участников**:
   - Имена/ники учеников и преподавателя не сохраняются на диске и не утекают в системные логи.

---

## 2. Реализованные меры защиты

### 2.1. Изоляция сети и строгий CSP (Content Security Policy)

- **Исключение внешних обращений**: в рантайме браузера фронтенд не делает ни одного внешнего HTTP- или WebSocket-запроса к сторонним доменам. Статические ассеты Excalidraw (шрифты, воркеры) загружаются исключительно с локального домена (`/`).
- **Строгий CSP**:
  - `default-src 'self'`
  - `script-src 'self'` (полностью устранён `'unsafe-inline'` и `'unsafe-eval'`; конфигурация ассетов перенесена в ESM-модуль `web/src/init.ts`)
  - `style-src 'self' 'unsafe-inline'`
  - `img-src 'self' data: blob:`
  - `font-src 'self' data:`
  - `connect-src 'self' ws: wss:`
  - `frame-ancestors 'none'` (запрет кликджекинга и встраивания в чужие iframe)
  - `object-src 'none'`
  - `base-uri 'self'`
- **Заголовки безопасности** (настроены в `web/public/_headers` и `worker/src/index.ts`):
  - `X-Content-Type-Options: nosniff`
  - `Referrer-Policy: no-referrer` (запрещает передачу ID доски в заголовке `Referer` при переходе по любым внешним ссылкам)
  - `X-Frame-Options: DENY`
  - `Permissions-Policy: camera=(), microphone=(), geolocation=(), payment=()`
  - `Strict-Transport-Security: max-age=31536000; includeSubDomains`
  - `X-Robots-Tag: noindex, nofollow`
  - `Cache-Control: no-store` для всех API-ответов (`/api/*`) и ошибок.

### 2.2. Защита интерфейса и санитизация DOM

- Из интерфейса Excalidraw программно удалены маркетинговые элементы, ссылки на Discord, Twitter/X, GitHub и Excalidraw+.
- Задействован `MutationObserver`, гарантирующий, что любые динамически добавленные внешние ссылки получают атрибуты `rel="noopener noreferrer"`.
- Мета-теги `robots` (`noindex, nofollow, noarchive`) и файл `robots.txt` (`Disallow: /`) запрещают поисковым роботам сканирование досок.

### 2.3. Защита Worker и Durable Objects

- **Проверка заголовка `Origin` при апгрейде WebSocket**:
  - Если заголовок `Origin` передан сторонним доменом (не совпадает с хостом воркера и не является localhost), соединение отклоняется с кодом `403 Forbidden`.
  - Предотвращает несанкционированное встраивание и эксплуатацию сокетов сторонними веб-страницами (Cross-Site WebSocket Hijacking).
- **Единый ответ 404 без пояснений**:
  - Запросы к несуществующим, некорректным (не base62) или не входящим в белый список `PILOT_BOARD_IDS` доскам возвращают идентичный ответ `404 Not Found` (`{"ok":false,"error":"Board not found"}`).
  - Устраняет возможность перебора и дифференциации валидных ID от невалидных.
- **Строгая проверка HTTP-методов**:
  - Эндпоинты `/api/*` принимают только документированные методы; остальные запросы возвращают `405 Method Not Allowed` с заголовком `Allow`.
  - Тела ответов об ошибках не ретранслируют пользовательский ввод.
- **Маскирование в логах (`boardRef`)**:
  - Полный ID доски **никогда** не пишется в консоль, логи воркера или вывод Cloudflare.
  - Вместо ID логируется `boardRef` — первые 8 hex-символов SHA-256 от ID доски.
  - Ники пользователей удалены из всех серверных логов событий.
- **Лимиты нагрузки**:
  - Ограничение размера сообщения: до 2 МБ.
  - Ограничение частоты сообщений: до 30 сообщений в секунду на клиента (с закрытием сокета 1008 при устойчивом превышении).
  - Ограничение числа одновременных участников: максимум 20 сокетов на одну доску.

## 3. Цепочка поставок и CI/CD

- Все GitHub Actions зафиксированы по полным immutable SHA коммитов (с комментариями тегов версий).
- В рабочих процессах выставлены минимальные права верхнего уровня: `permissions: contents: read`.
- Деплой в Cloudflare привязан к GitHub Environment `production` с ограничением развёртывания исключительно из защищённой ветки `main`.
- Настроен Dependabot (`.github/dependabot.yml`) для еженедельного аудита npm-пакетов и GitHub Actions.
- Файлы конфигурации инфраструктуры и безопасности защищены через `.github/CODEOWNERS`.

## 4. Остаточные риски и их минимизация

### 4.1. Авторизация по capability token (знание ID = полный доступ)

- **Суть риска**: в системе нет традиционной системы логинов и паролей. Тот, у кого есть ссылка вида `/b/<id>`, имеет полный доступ к чтению, рисованию и очистке холста.
- **Меры минимизации**:
  - Ссылки должны передаваться ученикам строго по защищённым каналам (личные сообщения Telegram, email, закрытый чат).
  - Преподаватель не должен публиковать ссылки на доски в открытых группах или социальных сетях.
  - В случае компрометации ссылки преподаватель создает новую доску (`npm run gen:board-id`) и переносит на неё материал через экспорт/импорт файла `.excalidraw`.

### 4.2. Риск исчерпания суточной квоты Workers (100 000 запросов)

- **Суть риска**: на стандартных поддоменах `*.workers.dev` невозможно включить Cloudflare WAF и продвинутый Rate Limiting зоны. Злоумышленник, узнавший корень сервиса, может направить поток HTTP-запросов и исчерпать суточный лимит бесплатного тарифа.
- **Меры минимизации**:
  - Не публиковать базовый адрес воркера в открытом доступе.
  - Доступ к доскам для учеников в фазе пилота ограничен белым списком `PILOT_BOARD_IDS`.
  - Для постоянной эксплуатации рекомендуется подключить собственный домен на бесплатном тарифе Cloudflare (что активирует WAF, Managed Rules и Cloudflare Rate Limiting).

### 4.3. Транзитивные уязвимости Excalidraw (`npm audit`)

- **Суть риска**: библиотека `@excalidraw/excalidraw` содержит глубокие транзитивные зависимости (`nanoid`, `mermaid`, `katex`, `lodash-es`), на которые `npm audit` сообщает предупреждения (Prototype Pollution, ReDoS).
- **Меры минимизации**:
  - Строгий CSP (`script-src 'self'`, `default-src 'self'`) блокирует любые попытки выполнения внешних скриптов или несанкционированных сетевых соединений в случае эксплуатации клиентской уязвимости.
  - Библиотека изолирована на клиенте; входные данные санитизируются перед обновлением состояния холста.
  - Еженедельный мониторинг через Dependabot для применения патчей по мере их выпуска авторами Excalidraw.
